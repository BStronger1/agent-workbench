## 保持不变的验收

1. 对 `selection-item` 执行 check。
2. 点击 `primary-action`。
3. `result` 可见文本精确等于“已完成 1 项”。

“实验准备”和“项目进度”仍为必需可见文本。验收契约的 SHA-256 与原测试逐项核对一致；没有使用 `.first()` 绕过重复定位，也没有自动修改模型产物来通过测试。

## 修复内容

- 编码与评审角色明确每个契约目标只能对应一个元素，列表其他项使用独立标识，分组计数使用 class。
- 静态验收提前发现重复标识，并反馈具体目标、匹配数量及改法。
- `check` 目标需要实际复选框/单选框、合法 ARIA 控件或关联 label；将标识放到外层容器会返回明确类型错误。动态创建的目标由浏览器执行时检查，保留原有合法 label 支持。
- 浏览器验收保留唯一定位与精确断言，反馈具体失败步骤及期望/实际文本，不返回 Playwright 堆栈或整段调用日志。
