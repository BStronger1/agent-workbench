- 后端 24 项单元测试通过：13 项工作流测试覆盖所有权隔离、快照不可变、重启状态恢复、失败更新回滚、记忆覆盖与停用、中文来源检索、三种上下文模式、结构验证、输入转义、有界修复、验收服务失败、Token 预算和未配置浏览器时的诚实状态；11 项模型配置测试覆盖加密存储、密文篡改与空间绑定、重启解密、Key 保留/替换/清除、接口域名限制、请求路由和配置不进入项目记录。
- TypeScript 类型检查与 Vue 生产构建通过。
- Playwright 端到端测试通过：界面创建项目、保存记忆、注入失效按钮、实际发现错误、修复后实际点击成功、文档来源检索、生成汇报、跨浏览器所有权隔离、拒绝无自定义头的写请求、移动端无横向溢出。
- 模型配置浏览器测试通过：自填接口与模型、保存和刷新恢复、响应掩码、空间隔离、禁止缓存、请求来源和接口限制、停用保留 Key、清除配置、移动端布局。使用明确的测试假 Key，外部模型调用为 0；后端请求与连接测试使用模拟 HTTP 响应验证路由及错误处理，不代表真实供应商测试。
- 固定演示评测 36 项全部完成：18 项首轮通过，18 项预设失效按钮在下一次确定性模板修复后通过，最终 36/36 通过；平均尝试次数 1.5。
- 最终 JAR 已在 Linux 服务器的独立 Java 21 / Node 22 环境部署；对实际部署的浏览器端到端回归通过，包含服务器侧 Chromium 验收与修复。超出 128 KiB 的写请求返回 413。

这不是“模型成功率从 50% 提升到 100%”。一半案例预先注入了已知交互缺陷；演示修复也是预定义行为。这些结果只证明验收与修复编排能发现该类缺陷并正确推进状态。
