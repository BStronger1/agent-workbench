# Provenance and scope

Agent Workbench was created for BStronger1 with AI-assisted development as an independently runnable implementation following a review of the educational project [yu-ai-code-mother](https://github.com/liyupi/yu-ai-code-mother) by liyupi.

The public repository contains newly authored workbench code, fixtures, documentation and verification artifacts. It does not redistribute the upstream project's implementation, course materials, visual assets or Git history. Upstream credit is retained here; a public source listing is not treated as a grant of redistribution rights.

The MIT license in this repository applies only to the new workbench implementation. Third-party dependencies retain their respective licenses. This repository makes no claim to original authorship of the upstream project.

Claims about implemented capabilities and measured results are limited to the recorded tests. Demo fixtures are deterministic; they do not measure LLM quality or establish memory-retrieval improvements. Live model integration remains unverified until the owner supplies API configuration and performs actual runs.
